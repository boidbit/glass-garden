# Kaanch Run

A Smash Hit style glass run, made with Godot 4.3 (separate from the web game, which stays as it is).

You fly down a hall of rooms. Tap to throw balls and break the glass before you reach it: thin glass breaks at once, thick green glass takes two hits, very thick three. Running into glass costs ten balls; crystals give three, and ten in a row give two balls a throw. Each room ends at a checkpoint door.

Every push that changes this folder builds an APK on GitHub (**Actions → Kaanch Run APK**) and puts it on the [run-latest release](../../../releases/tag/run-latest) as `KaanchRun.apk`. It installs next to Kaanch Ka Kamra.

Run it on a computer: open this folder in Godot 4.3, or `godot --path kaanch-run`.
